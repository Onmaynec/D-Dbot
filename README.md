## ✨ Что нового

Следующее крупное обновление превращает бота из генератора событий в более цельную RPG-систему.

- 👥 несколько Telegram-пользователей могут вступить в общую партию;
- 🧙 каждому участнику партии автоматически создаётся собственный герой;
- 📊 сложность боя рассчитывается по среднему уровню партии;
- 🎒 добыча автоматически сохраняется в общий инвентарь;
- 💰 у партии появилась общая казна;
- 🏪 добавлена лавка с предметами, ценами и кнопками покупки;
- 🧪 лечебные зелья можно использовать прямо из инвентаря;
- 🎲 в начале боя бот бросает инициативу за героев и врагов;
- 🩸 после атаки или заклинания враги совершают ответный ход;
- ☠️ бой может закончиться не только победой, но и поражением;
- 💾 партия, инвентарь, золото и состояние боя сохраняются в SQLite.

## 👥 Система партии

В групповом Telegram-чате каждый игрок нажимает:

```text
👥 Партия → ➕ Вступить в партию
```

Бот создаёт для него отдельного случайного героя и сохраняет его по паре `chat_id + user_id`.

Состав партии показывает:

- имя пользователя Telegram;
- имя персонажа;
- расу и класс;
- текущий уровень.

Уровень угрозы в бою рассчитывается по среднему уровню всех участников. Если партия не создана, используется уровень основного героя чата.

## 🎒 Инвентарь и экономика

Каждый чат получает:

- общий инвентарь;
- общую казну со стартовыми `100` золотыми;
- автоматическое объединение одинаковых предметов;
- сохранение количества и редкости предметов.

При нажатии `💎 Добыча` найденный предмет сразу попадает в рюкзак, а партия получает несколько монет. Размер денежной награды зависит от редкости добычи.

Лечебные предметы:

| Предмет | Эффект |
|---|---|
| Зелье лечения | `1d8 + 2` HP |
| Большое зелье лечения | `2d8 + 4` HP |

Бот не позволяет использовать зелье, если здоровье героя уже заполнено.

## 🏪 Лавка

В магазине доступны:

- зелья лечения;
- противоядие;
- свиток щита;
- серебряные стрелы;
- перо феникса.

Покупка проходит через inline-кнопки. Бот атомарно проверяет баланс, списывает золото и добавляет предмет в инвентарь.

## ⚔️ Обновлённая боевая система

При запуске боя бот:

1. рассчитывает уровень партии;
2. генерирует подходящих противников;
3. бросает инициативу за героев и каждого врага;
4. сохраняет порядок инициативы в состоянии боя;
5. показывает доступные цели кнопками.

После атаки или боевого заклинания каждый живой противник получает ответный ход:

- бросает `d20` против КД героя;
- может промахнуться, попасть или нанести критический удар;
- уменьшает сохранённые HP героя;
- переводит бой в следующий раунд.

Если HP основного героя опускаются до нуля, активный бой завершается поражением. После отдыха герой снова восстанавливается полностью.

## 🖼️ Визуальный интерфейс

Все игровые действия сопровождаются тематическими иллюстрациями:

- кампания и мир;
- персонажи и NPC;
- квесты и встречи;
- добыча и магазин;
- атаки, магия и бой;
- отдых, повышение уровня и журнал.

Изображения встроены в Python-модули и автоматически распаковываются в `data/button_ui_images/` при первом запуске.

## 💾 SQLite

База создаётся автоматически и содержит таблицы:

| Таблица | Назначение |
|---|---|
| `campaigns` | текущие кампании |
| `characters` | основные герои чатов |
| `party_members` | участники многопользовательской партии |
| `inventory` | общие предметы и их количество |
| `party_wallets` | общая казна |
| `combats` | активные бои и инициатива |
| `journal` | история игровых событий |

Существующие базы обновляются безопасно: новые таблицы создаются через `CREATE TABLE IF NOT EXISTS`, поэтому старые кампании и персонажи не удаляются.

## 🚀 Быстрый запуск

```bash
git clone https://github.com/Onmaynec/D-Dbot.git
cd D-Dbot
python -m venv .venv
```

Активация окружения:

```bash
# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Создай `.env`:

```env
BOT_TOKEN=токен_от_BotFather
DATABASE_PATH=data/dnd_bot.sqlite3
LOG_LEVEL=INFO
```

Запуск:

```bash
python -m app.main
```

После обновления отправь боту `/start`, чтобы Telegram заменил старую клавиатуру новым меню.

## 🐳 Docker

docker compose up -d --build

SQLite хранится в локальной папке `data/` и сохраняется при пересборке контейнера.
