## 🏰 Что нового в 4.0

Версия **4.0.0** добавляет полноценные экспедиции и исправляет низкое качество изображений.

- 🕯️ постоянные походы по процедурно созданным подземельям;
- 🚪 сохранение активной экспедиции между перезапусками;
- 📚 комнаты с тайнами, ловушками, сокровищами, святилищами и событиями;
- 🐉 финальный босс с отдельными HP, КД, атаками, критами и ответными ударами;
- 💰 золото, опыт и легендарная добыча за победу;
- 💀 три сложности: лёгкая, обычная и хардкор;
- 🏆 отдельная статистика и достижения исследователя подземелий;
- 🎛️ настройки игрового чата;
- 🖼️ автоматическая подготовка крупных сцен 1280×960 вместо прежних миниатюр 240×180;
- 📎 режим отправки изображений документом без сжатия Telegram;
- 💾 всё новое состояние сохраняется в SQLite.

## 🛠️ Исправление качества изображений

Раньше встроенные изображения распаковывались как миниатюры около `240×180`, а Telegram дополнительно сжимал их. В v4 бот при первом запуске автоматически создаёт улучшенную версию каждой сцены размером `1280×960`:

- масштабирование выполняется фильтром Lanczos;
- основная сцена сохраняет пропорции;
- свободное пространство заполняется мягким размытым фоном вместо чёрных полос;
- после увеличения применяется аккуратная резкость;
- JPEG сохраняется с качеством `94`;
- готовые файлы кэшируются в `data/button_ui_images_v4/`.

В разделе `🎛️ Настройки` доступны режимы:

| Режим | Поведение |
|---|---|
| `🖼️ Фото высокого качества` | Крупная сцена показывается прямо в сообщении |
| `📎 Оригинал без сжатия` | Тот же крупный файл отправляется документом без дополнительного сжатия Telegram |

При наличии собственных полноразмерных файлов в `assets/images_hq/` бот использует их напрямую. Иначе улучшенная версия строится из уже встроенных иллюстраций.

## 🕯️ Экспедиции по подземельям

Перед началом бот определяет средний уровень партии и выбранную сложность. Затем создаётся подземелье на несколько комнат:

| Сложность | Комнат | Опасность | Награды |
|---|---:|---:|---:|
| Лёгкая | 4 | сниженная | немного меньше |
| Обычная | 5 | стандартная | стандартные |
| Хардкор | 6 | повышенная | увеличенные |

Возможные комнаты:

- 📚 сюжетная находка;
- ⚠️ ловушка с уроном;
- 💎 сокровищница с золотом и предметом;
- ✨ святилище с лечением;
- 👁️ тревожная встреча;
- 🐉 тронный зал финального босса.

Игрок может в любой момент посмотреть состояние экспедиции или отступить. Уже полученные предметы и золото сохраняются.

## 🐉 Битвы с боссами

Финальный противник масштабируется по уровню группы и сложности. Бой поддерживает:

- бросок `d20` против КД босса;
- бонус атаки и владения героя;
- обычный и критический урон;
- ответный удар босса;
- сохранение HP босса и героя;
- поражение при падении HP до нуля;
- золото, XP и легендарный предмет за победу.

## 💾 SQLite

Новые таблицы версии 4.0:

| Таблица | Назначение |
|---|---|
| `dungeon_runs` | активная экспедиция и состояние босса |
| `dungeon_history` | история побед, поражений и отступлений |
| `chat_game_settings` | сложность и режим изображений |
| `dungeon_stats` | комнаты, экспедиции, боссы и отступления |
| `dungeon_achievements` | достижения подземелий |

Таблицы создаются через `CREATE TABLE IF NOT EXISTS`, поэтому старая база обновляется без удаления кампаний, персонажей, предметов и журнала.

## 🚀 Запуск

```bash
git clone https://github.com/Onmaynec/D-Dbot.git
cd D-Dbot
python -m venv .venv
```

Активация окружения:

```bash
# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

Установка:

```bash
pip install -r requirements.txt
```

Создай `.env`:

```env
BOT_TOKEN=токен_от_BotFather
DATABASE_PATH=data/dnd_bot.sqlite3
LOG_LEVEL=INFO
```

Запуск:

```bash
python -m app.main
```

После обновления отправь боту `/start`, чтобы Telegram заменил старую клавиатуру.

## 🐳 Docker

```bash
docker compose up -d --build
```

Папка `data/` подключена как volume и сохраняет SQLite между пересборками.
