## 🎁 Что нового в 4.2

Версия **4.2.0** добавляет ежедневный сундук партии и систему серии посещений.

- команда `/daily` открывает статус и предпросмотр награды;
- одна награда доступна каждому чату раз в календарный день UTC;
- золото сразу попадает в общую казну партии;
- каждый третий последовательный день выдаётся бонусный предмет;
- каждый седьмой день выдаётся эпический **Жетон судьбы** и дополнительное золото;
- пропуск дня сбрасывает текущую серию, но не общую статистику;
- повторные клики и одновременные запросы не могут выдать награду дважды;
- отметка о получении, золото и предмет записываются одной SQLite-транзакцией.

```text
/daily → Получить награду → золото и предмет добавляются в общую казну
```

## 🛡️ Надёжность 4.1

При каждом запуске бот создаёт консистентную резервную копию SQLite через штатный Backup API и проверяет её целостность.

```env
BACKUP_ON_START=true
BACKUP_DIR=data/backups
BACKUP_KEEP=7
```

Команда `/status` показывает:

- текущую версию приложения;
- результат `PRAGMA quick_check`;
- размер файла базы данных.

Ошибки резервного копирования записываются в лог, но не останавливают запуск бота.

## 🕯️ Подземелья и боссы

Экспедиция сохраняется между перезапусками. Количество комнат зависит от сложности:

| Сложность | Комнат | Риск | Награды |
|---|---:|---:|---:|
| Лёгкая | 4 | сниженный | немного меньше |
| Обычная | 5 | стандартный | стандартные |
| Хардкор | 6 | высокий | увеличенные |

В подземельях встречаются сюжетные находки, ловушки, сокровищницы, святилища, случайные события и финальный босс. Состояние босса, HP героев, добыча и история походов хранятся в SQLite.

## 🚀 Запуск

```bash
git clone https://github.com/Onmaynec/D-Dbot.git
cd D-Dbot
python -m venv .venv
```

Активация окружения:

```bash
# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Создай `.env`:

```env
BOT_TOKEN=токен_от_BotFather
DATABASE_PATH=data/dnd_bot.sqlite3
LOG_LEVEL=INFO
BACKUP_ON_START=true
BACKUP_DIR=data/backups
BACKUP_KEEP=7
```

Запуск:

```bash
python -m app.main
```

После обновления отправь боту `/start`, чтобы Telegram обновил список команд и клавиатуру.

docker compose up -d --build

## 🧪 Проверка

```bash
pip install -r requirements-dev.txt
ruff check . --select E9,F63,F7,F82
pytest -q
```

CI выполняется на Python 3.11 и 3.12. Тесты покрывают:

- генерацию и прохождение подземелий;
- бои с боссами и расчёт наград;
- подготовку HQ-сцен;
- резервные копии и проверку SQLite;
- ежедневные серии, milestone-награды и защиту от повторного получения.

## 💾 Хранение данных

Основные SQLite-таблицы:

| Таблица | Назначение |
|---|---|
| `campaigns` | Мир и активная кампания чата |
| `characters` | Основные герои |
| `party_members` | Участники многопользовательской партии |
| `inventory` | Общие предметы и расходники |
| `party_wallets` | Общая казна |
| `combats` | Состояние активного боя |
| `dungeon_runs` | Активная экспедиция |
| `dungeon_history` | Результаты походов |
| `daily_rewards` | Дата получения, серия и общая статистика сундука |
| `journal` | Летопись событий |

Все таблицы создаются через `CREATE TABLE IF NOT EXISTS`, поэтому обновление не удаляет существующие кампании.

## 🔐 Безопасность

- не публикуй `.env` и токен Telegram;
- при утечке отзови токен через BotFather;
- файлы SQLite, резервные копии и сгенерированные изображения исключены из Git;
- пользовательский текст экранируется перед отправкой в HTML-режиме;
- не отправляй файл базы данных в публичные чаты.
