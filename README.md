## ⚒️ Что нового в 4.3

Версия **4.3.0** добавляет кузницу и переработку лишней добычи.

- команда `/forge` открывает рецепты и список предметов для разбора;
- ингредиенты и золото списываются одной SQLite-транзакцией;
- при нехватке ресурсов ничего не теряется;
- обычные, редкие, эпические и легендарные предметы имеют разную стоимость разбора;
- разобранный предмет превращается в золото общей казны;
- операции сохраняются в таблице `forge_history`;
- устаревшая кнопка не может удалить другой предмет;
- после зелёного CI версия автоматически публикуется как GitHub Release с тегом.

### Рецепты

|---|---|---:|
| Большое зелье лечения | 2 × Зелье лечения | 15 зм. |

```text
/forge → выбрать рецепт или разобрать предмет → обновить казну и инвентарь
```

## 🎁 Ежедневные награды 4.2

Команда `/daily` выдаёт одну награду на чат за календарный день UTC.

- золото поступает в общую казну;
- каждый третий последовательный день выдаётся предмет;
- каждый седьмой — эпический Жетон судьбы и дополнительное золото;
- пропуск дня сбрасывает серию;
- повторные и параллельные запросы не выдают награду дважды.

## 🛡️ Надёжность 4.1

При каждом запуске бот создаёт консистентную резервную копию SQLite через штатный Backup API.

```env
BACKUP_ON_START=true
BACKUP_DIR=data/backups
BACKUP_KEEP=7
```

Команда `/status` показывает версию, размер базы и результат `PRAGMA quick_check`.

## 🚀 Запуск

```bash
git clone https://github.com/Onmaynec/D-Dbot.git
cd D-Dbot
python -m venv .venv
```

Активация окружения:

```bash
# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

Установка:

```bash
pip install -r requirements.txt
```

Создай `.env`:

```env
BOT_TOKEN=токен_от_BotFather
DATABASE_PATH=data/dnd_bot.sqlite3
LOG_LEVEL=INFO
BACKUP_ON_START=true
BACKUP_DIR=data/backups
BACKUP_KEEP=7
```

Запуск:

```bash
python -m app.main
```

После обновления перезапусти бота и отправь `/start`.

## 🐳 Docker

```bash
docker compose up -d --build
```

## 🧪 Проверка

```bash
pip install -r requirements-dev.txt
ruff check . --select E9,F63,F7,F82
pytest -q
```

CI выполняется на Python 3.11 и 3.12. После успешного CI на `main` release-job:

1. читает версию из `app.__version__`;
2. создаёт тег `v<version>`;
3. создаёт GitHub Release;
4. устанавливает `make_latest: true`.

## 💾 Хранение данных

| Таблица | Назначение |
|---|---|
| `campaigns` | Мир и активная кампания |
| `characters` | Основные герои |
| `party_members` | Участники партии |
| `inventory` | Общие предметы |
| `party_wallets` | Общая казна |
| `combats` | Активный бой |

## 🔐 Безопасность

- SQLite, резервные копии и кэш изображений исключены из Git;
- пользовательский текст экранируется для HTML;
- не отправляй базу данных в публичные чаты.
