## ✨ Что нового

Игровой процесс больше не требует ручного ввода команд. После `/start` бот показывает постоянное меню Telegram с красивыми кнопками, а каждое игровое событие сопровождается тематической иллюстрацией.

- 🎛️ постоянная нижняя клавиатура для основных действий;
- 🧭 контекстные кнопки под сообщениями;
- 🗡️ выбор противника кнопкой во время боя;
- 🎲 панель для `d4`, `d6`, `d8`, `d10`, `d12`, `d20`, `d100`, `2d6` и `d20+3`;
- ✨ готовые заклинания и ввод собственного названия;
- 🖼️ 16 игровых иллюстраций для мира, героев, встреч, боя, отдыха и добычи;
- 📤 экспорт летописи в TXT с тематической миниатюрой;
- 🛡️ старые slash-команды сохранены как резервный интерфейс.

## 🎮 Главное меню

| Кнопка | Действие |
|---|---|
| `🏕️ Кампания` | Создать новый мир или посмотреть текущую кампанию |
| `🧙 Герой` | Создать персонажа, открыть лист героя или повысить уровень |
| `📜 Квест` | Получить случайное задание |
| `🎭 NPC` | Встретить персонажа с характером, секретом и отношением к партии |
| `🌍 Встреча` | Сгенерировать дружелюбное, нейтральное или враждебное событие |
| `🎒 Добыча` | Найти предмет случайной редкости |
| `⚔️ Бой` | Начать бой, выбрать цель и проверить состояние врагов |
| `🎲 Кубы` | Открыть панель бросков |
| `✨ Магия` | Выбрать готовое или придумать собственное заклинание |
| `🛌 Отдых` | Восстановить хиты и получить событие ночлега |
| `📖 Журнал` | Посмотреть последние события и экспортировать летопись |
| `⚙️ Ещё` | Помощь, повышение уровня и дополнительные действия |

## 🗺️ Возможности

- генерация кампании, жанра мира и трёх фракций;
- случайные персонажи с расой, классом, предысторией и характеристиками;
- квесты с заказчиком, целью, наградой и осложнением;
- NPC с внешностью, характером, секретом и отношением к героям;
- встречи трёх типов и добыча четырёх редкостей;
- боевая система с КД, броском d20, модификаторами, уроном и критами;
- выбор живой цели кнопкой, боевые заклинания, опыт и повышение уровня;
- восстановление хитов и случайные события ночлега;
- runtime-кэш сессий в обычном `dict`;
- постоянное хранение кампаний, героев, боёв и журнала в SQLite;
- экспорт полной истории в TXT.

## 🚀 Быстрый запуск

### 1. Клонируй проект

```bash
git clone https://github.com/Onmaynec/D-Dbot.git
cd D-Dbot
python -m venv .venv
```

Активируй окружение:

```bash
# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

### 2. Установи зависимости

```bash
pip install -r requirements.txt
```

### 3. Настрой бота

```bash
cp .env.example .env
```

Добавь токен, полученный у [@BotFather](https://t.me/BotFather):

```env
BOT_TOKEN=токен_от_BotFather
DATABASE_PATH=data/dnd_bot.sqlite3
LOG_LEVEL=INFO
```

### 4. Запусти

```bash
python -m app.main
```

Открой бота в Telegram, отправь `/start` и дальше используй кнопки меню.

## 🔄 Обновление существующей установки

```bash
git pull
python -m app.main
```

Для Docker:

```bash
git pull
docker compose up -d --build
```

Существующая SQLite-база в `data/` сохраняется — кампании, герои и журнал не удаляются.

## 🐳 Docker

```bash
cp .env.example .env
# Добавь BOT_TOKEN в .env
docker compose up -d --build
```

SQLite хранится в локальной папке `data/` и переживает перезапуск контейнера.

## 🖼️ Иллюстрации

Все присланные игровые сцены встроены в Python-модули в оптимизированном JPEG-виде. При первом запуске `media.py` автоматически распаковывает их в:

```text
data/button_ui_images/
```

Папка создаётся автоматически. В неё попадают сцены приветствия, кампании, героя, квеста, NPC, трёх типов встреч, боя, атаки, заклинания, отдыха, повышения уровня, двух категорий добычи и журнала.

Длинные ответы автоматически делятся на несколько подписей; каждая часть всё равно отправляется с тематической картинкой.

## 💾 Хранилище

SQLite создаётся автоматически при первом запуске и содержит таблицы:

- `campaigns` — текущая кампания чата;
- `characters` — герои и их развитие;
- `journal` — летопись игровых событий;
- `combats` — состояние активного боя.

Каждый Telegram-чат получает независимую кампанию, персонажа, бой и журнал.
