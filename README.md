## 🌟 Campaign 2.0

Версия **3.0.0** превращает набор случайных событий в связанную кампанию с долгосрочным прогрессом.

- 📜 одновременно можно вести несколько активных контрактов;
- 🎯 у каждого квеста есть этапы и отображаемый прогресс;
- ✅ завершённые контракты выдают золото и репутацию;
- 🗺️ путешествия открывают новые локации и двигают активные задания;
- 🏛️ отношения с фракциями меняются от действий партии;
- 🏆 достижения открываются автоматически по статистике кампании;
- 💾 квесты, текущая локация, репутация, статистика и достижения сохраняются в SQLite;
- 🛡️ старые кампании, герои, предметы и журналы остаются совместимыми.

## 📜 Активные контракты

Кнопка `📜 Квесты` открывает отдельный центр заданий.

Каждый контракт содержит:

- заказчика;
- цель и осложнение;
- связанную фракцию;
- количество необходимых этапов;
- денежную награду;
- награду репутацией;
- дополнительный сюжетный приз.

Этап можно выполнить кнопкой `🎯 Выполнить этап`. Путешествие также автоматически продвигает один незавершённый контракт. После заполнения шкалы появляется кнопка `✅ Завершить и получить награду`.

Активные, завершённые и оставленные контракты сохраняются независимо от перезапуска бота.

## 🗺️ Путешествия и локации

Каждая экспедиция создаёт новую сцену с:

- названием локации;
- типом местности;
- локальной угрозой;
- уникальной находкой;
- влияющей фракцией;
- найденными монетами.

Путешествия увеличивают статистику кампании, могут улучшить репутацию и помогают выполнять активные квесты. Последняя открытая локация доступна через кнопку `📍 Текущее местоположение`.

## 🏛️ Репутация фракций

У каждой фракции есть показатель от `-10` до `+10`.

| Значение | Отношение |
|---:|---|
| `-10…-6` | заклятые враги |
| `-5…-3` | враждебность |
| `-2…-1` | недоверие |
| `0` | нейтрально |
| `1…2` | уважение |
| `3…5` | союзники |
| `6…10` | легендарные друзья |

Завершение контрактов повышает отношение фракции-заказчика. Некоторые дорожные события также дают репутацию.

## 🏆 Достижения

В версии 3.0 доступны:

- **Первый контракт** — завершить первый активный квест;
- **Следопыт** — совершить три путешествия;
- **Надёжный союзник** — получить репутацию `+3`;
- **Ветеран контрактов** — завершить пять квестов;
- **Живая легенда** — завершить десять квестов и совершить десять путешествий.

Бот проверяет условия автоматически и показывает уведомление сразу после открытия достижения.

## 👥 Партия, инвентарь и экономика

В групповом чате каждый пользователь может вступить в общую партию и получить собственного героя. Сложность боя рассчитывается по среднему уровню участников.

У чата есть общие:

- инвентарь;
- казна со стартовыми `100` золотыми;
- магазин;
- найденная добыча;
- сюжетный прогресс кампании.

Лечебные зелья используются прямо из инвентаря, а покупки выполняются атомарно через SQLite.

## ⚔️ Боевая система

Бот поддерживает:

1. генерацию врагов по уровню партии;
2. бросок инициативы;
3. выбор живой цели кнопкой;
4. бросок `d20` с модификаторами;
5. попадания, промахи и критические удары;
6. заклинания с отдельной проверкой;
7. ответный ход каждого живого врага;
8. сохранение HP и текущего раунда;
9. опыт, повышение уровня, победу и поражение.

## 🖼️ Иллюстрации

Все основные события сопровождаются тематическими изображениями:

- начало кампании;
- герои и NPC;
- контракты;
- путешествия и встречи;
- добыча и магазин;
- бой, атака и магия;
- отдых, повышение уровня и достижения.

Изображения встроены в Python-модули и распаковываются в `data/button_ui_images/` при первом запуске.

## 💾 SQLite

Основные таблицы:

| Таблица | Назначение |
|---|---|
| `campaigns` | текущий мир и фракции |
| `characters` | основные герои чатов |
| `party_members` | участники партии |
| `inventory` | предметы и количество |
| `party_wallets` | общая казна |
| `combats` | активные бои и инициатива |
| `journal` | летопись событий |
| `campaign_quests` | активные, завершённые и оставленные контракты |
| `campaign_locations` | последняя открытая локация |
| `faction_reputation` | отношения партии с фракциями |
| `campaign_stats` | квесты, путешествия и выполненные этапы |
| `campaign_achievements` | открытые достижения |

Новые таблицы создаются через `CREATE TABLE IF NOT EXISTS`. Обновление не удаляет существующую базу.

## 🚀 Запуск

```bash
git clone https://github.com/Onmaynec/D-Dbot.git
cd D-Dbot
python -m venv .venv
```

Активация окружения:

```bash
# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

Установка:

```bash
pip install -r requirements.txt
```

Создай `.env`:

```env
BOT_TOKEN=токен_от_BotFather
DATABASE_PATH=data/dnd_bot.sqlite3
LOG_LEVEL=INFO
```

Запуск:

```bash
python -m app.main
```

После обновления отправь `/start`, чтобы Telegram заменил старую клавиатуру меню.

## 🐳 Docker

```bash
docker compose up -d --build
```

Папка `data/` подключена как volume, поэтому SQLite сохраняется между пересборками.
