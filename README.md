## Что изменилось в v5

Версия 5.0 перерабатывает проект из набора отдельных генераторов в связанную игру с понятным циклом:

```text
создать героя → выбрать снаряжение → принять решение → вступить в бой
→ распределить ходы партии → получить XP, золото и трофей → улучшить экипировку
```

### ⚔️ Интерактивный бой

В партийном бою каждый живой игрок делает один ход за раунд. Помимо обычной атаки и магии доступны:

- **рискованный удар**: `−2` к попаданию и `+4` к урону;
- **защитная стойка**: повышает КД до следующей фазы врагов и ослабляет входящий удар;
- **лечение союзника** через `/support`;
- **боевые реликвии** через `/tactics`;
- **все варианты хода** через `/actions`.

Враги выбирают отдельные цели, броня меняет КД, оружие усиливает физический урон, а посохи и талисманы — магический.

### 🧰 Оружие и экипировка

Команда `/equipment` открывает личное снаряжение героя.

| Слот | Примеры | Эффект |
|---|---|---|
| Оружие | меч, лук, секира, посох, клинок Бездны | физический или магический урон |
| Доспех | кожа, кольчуга, драконья кираса | бонус КД |
| Талисман | талисман удачи, перстень хранителя, медальон феникса | смешанные бонусы |

Покупки используют общую казну, но предмет принадлежит конкретному игроку. Переодеваться во время боя нельзя.

### 🧭 Сюжетные решения

Команда `/choice` создаёт событие с тремя вариантами. Каждый вариант использует одну из характеристик партии и может:

- принести золото или редкий предмет;
- открыть безопасный путь;
- потратить часть казны;
- нанести урон всем живым героям.

Результат определяется броском `d20` и средней характеристикой участников, поэтому состав партии действительно влияет на прохождение.

### 🎰 Казино

Команда `/casino` открывает таверну «Золотой мимик»:

- монета судьбы;
- кости против крупье;
- рунный автомат с парами, тройками и джекпотом.

Используется только внутриигровое золото. Дневной лимит ставок защищает общую казну от полного разорения.

### 🖼️ Полноразмерные сцены

Система изображений теперь предпочитает исходные PNG из `assets/images_hq/`.

- режим **PNG без сжатия** отправляет картинку Telegram-документом и отдельную форматированную карточку сообщения;
- режим **быстрое фото** отправляет изображение как обычное Telegram-фото;
- старые встроенные JPG остаются резервным вариантом;
- `scripts/verify_hq_assets.py` сверяет каждый PNG с SHA256 исходной загрузки;
- `scripts/install_hq_assets.ps1` устанавливает скачанные по отдельности PNG без перекодирования.

При первом `/start` после обновления режим PNG без сжатия включается один раз. После этого его можно изменить в настройках.

## Установка

```bash
git clone https://github.com/Onmaynec/D-Dbot.git
cd D-Dbot
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Linux/macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

Создай `.env`:

```env
BOT_TOKEN=токен_от_BotFather
DATABASE_PATH=data/dnd_bot.sqlite3
LOG_LEVEL=INFO
BACKUP_ON_START=true
BACKUP_DIR=data/backups
BACKUP_KEEP=7
```

Запуск:

```bash
python -m app.main
```

После обновления отправь боту `/start`.

## Установка PNG без архива

Скачай 16 присланных PNG по отдельности в папку `Загрузки`, затем выполни:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install_hq_assets.ps1
python scripts\verify_hq_assets.py
```

Скрипт не меняет формат, размер или пиксели. Он копирует исходные файлы и проверяет SHA256.

## Проверка

```bash
pip install -r requirements-dev.txt
ruff check . --select E9,F63,F7,F82
pytest -q
python scripts/verify_hq_assets.py
```

CI выполняется на Python 3.11 и 3.12. После зелёного CI на `main` создаются тег и GitHub Release со статусом Latest. Если PNG уже установлены в `assets/images_hq/`, workflow прикладывает их к релизу отдельными файлами; иначе используй присланные отдельно оригиналы и установщик.

## Безопасность и надёжность

- изменения золота, предметов, HP и боевых ходов выполняются транзакциями SQLite;
- повторный callback не выдаёт второй предмет и не создаёт дополнительный ход;
- экипировка блокируется во время боя;
- сюжетные решения блокируются во время боя;
- казино проверяет баланс и дневной лимит внутри `BEGIN IMMEDIATE`;
- резервная копия SQLite создаётся при запуске.
