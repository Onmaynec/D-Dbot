## ✨ Что умеет бот

Бот превращает Telegram-чат в живую игровую сессию. Он говорит голосом мастера подземелий, помнит текущую кампанию и записывает каждое важное событие в летопись.

- 🎲 бросает `d4`, `d6`, `d8`, `d10`, `d12`, `d20`, `d100`, включая форматы `2d6+3`;
- 🧙 создаёт персонажей с расой, классом, предысторией, характеристиками и хитами;
- 🌍 генерирует кампанию, жанр мира и три противоборствующие фракции;
- 📜 создаёт квесты, NPC, встречи и добычу четырёх редкостей;
- ⚔️ проводит бой, считает попадание, урон, критические удары и опыт;
- ✨ описывает заклинания и выполняет проверку против цели;
- ⬆️ предлагает развитие героя при повышении уровня;
- 🔥 восстанавливает хиты во время отдыха и создаёт ночное событие;
- 💾 хранит кампании, персонажей, журнал и бой в SQLite;
- 📤 экспортирует полную летопись в TXT.

## 🗺️ Команды

| Команда | Описание |
|---|---|
| `/campaign [название]` | Начать кампанию и сгенерировать мир |
| `/character` | Создать случайного персонажа |
| `/quest` | Получить случайный квест |
| `/roll [кубик]` | Бросить кубик, например `/roll d20+4` |
| `/npc` | Создать атмосферного NPC с секретом |
| `/encounter` | Сгенерировать случайную встречу |
| `/loot` | Найти добычу со случайной редкостью |
| `/combat` | Начать бой с врагами по уровню партии |
| `/attack [цель]` | Атаковать врага по номеру или имени |
| `/spell [название]` | Сотворить заклинание и выполнить бросок |
| `/rest` | Восстановить хиты и пережить событие ночлега |
| `/levelup` | Проверить опыт и выбрать развитие героя |
| `/journal` | Показать последние записи сессии |
| `/export` | Скачать весь журнал в TXT |
| `/help` | Открыть гримуар команд |

## 🚀 Быстрый запуск

### 1. Получи токен

Создай бота через [@BotFather](https://t.me/BotFather), выполни `/newbot` и сохрани токен.

### 2. Установи проект

```bash
git clone https://github.com/Onmaynec/D-Dbot.git
cd D-Dbot
python -m venv .venv
```

Активируй окружение:

```bash
# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

Установи зависимости:

```bash
pip install -r requirements.txt
```

### 3. Настрой окружение

```bash
cp .env.example .env
```

Открой `.env` и замени токен:

```env
BOT_TOKEN=токен_от_BotFather
DATABASE_PATH=data/dnd_bot.sqlite3
LOG_LEVEL=INFO
```

### 4. Запусти

```bash
python -m app.main
```

## 🐳 Запуск через Docker

```bash
cp .env.example .env
# Добавь BOT_TOKEN в .env
docker compose up -d --build
```

База хранится в локальной папке `data/`, поэтому переживает перезапуск контейнера.

## 🧱 Архитектура

```text
app/
├── main.py         # запуск aiogram и меню команд
├── handlers.py     # Telegram-команды и кнопки
├── generators.py   # персонажи, миры, квесты, NPC, события
├── combat.py       # враги, атаки и заклинания
├── dice.py         # разбор и броски кубиков
├── database.py     # асинхронная работа с SQLite
├── session.py      # runtime-кэш сессии в dict + сохранение
└── config.py       # переменные окружения
```

Во время работы данные текущей сессии находятся в `SessionStore.sessions` — обычном словаре Python. Каждая запись одновременно сохраняется в SQLite, поэтому история не исчезает после перезапуска.

## 💾 Данные

SQLite создаётся автоматически при первом запуске. Используются таблицы:

- `campaigns` — текущая кампания чата;
- `characters` — созданные герои и прогресс;
- `journal` — броски, квесты, NPC, добыча и события;
- `combats` — состояние активного боя.

Один Telegram-чат получает одну независимую текущую кампанию и собственный журнал.
