## Расширенное описание

D&D Telegram Master превращает групповой чат в постоянную RPG. Adventure Reforged связывает героев, личную экипировку, партийные раунды, рискованные атаки, защитные стойки, лечение, тактические реликвии, сюжетные решения, подземелья, крафт, общую казну и награды за победы. Казино добавляет азарт на внутриигровое золото с дневным лимитом, а шестнадцать полноразмерных PNG-сцен могут отправляться Telegram-документами без повторного сжатия. Все важные изменения состояния сериализуются транзакциями SQLite, а база резервируется при запуске.
