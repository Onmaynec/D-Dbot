# Описание репозитория

## Короткое описание для поля About

> 🐉 Атмосферный Telegram-мастер для D&D на Python и aiogram: кампании, персонажи, квесты, NPC, кубы, бой, прокачка, SQLite и экспорт журнала.

## Темы GitHub

`telegram-bot` · `aiogram` · `python` · `dnd` · `dungeons-and-dragons` · `sqlite` · `rpg` · `game-master`

## Расширенное описание

D&D Telegram Master превращает чат в интерактивный стол приключений. Бот создаёт мир и фракции, генерирует героев, NPC, задания, встречи и добычу, проводит бои с бросками d20, начисляет опыт и хранит полную летопись кампании в SQLite.
