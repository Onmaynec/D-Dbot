## Расширенное описание

D&D Telegram Master превращает групповой чат в постоянную RPG-кампанию. Бот создаёт мир, фракции и героев, ведёт активные контракты с прогрессом, открывает новые локации, рассчитывает репутацию, выдаёт достижения, управляет общим инвентарём и проводит инициативные бои. Весь прогресс хранится в SQLite и переживает перезапуск.
