# D&D Telegram Master v4.4.0 — Tactical Items

Version 4.4.0 connects the v4.3 forge to the combat system.

## New

- `/tactics` opens tactical inventory during an active battle.
- Shield Scroll grants +2 armor class for the next two enemy phases.
- Phoenix Feather automatically revives the active hero with half maximum HP.
- Active tactical effects appear in combat status.
- Effects are persisted in SQLite together with the combat state.
- Item activation and combat-state update happen in one transaction.
- Duplicate and concurrent activation attempts cannot consume extra items.
- Activations are recorded in `combat_item_history`.

## Compatibility

- Shield Scrolls and Phoenix Feathers crafted in v4.3 work immediately.
- Existing databases, combats, campaigns, and inventories remain compatible.
- No Telegram token or environment configuration changes are required.

## Upgrade

Pull the latest `main`, install dependencies, restart the bot, and send `/start`:

```bash
git pull
pip install -r requirements.txt
python -m app.main
```

Start a battle and open the new system with `/tactics`.
