# D&D Telegram Master v4.7.0 — Victory Rewards

Version 4.7.0 closes the multiplayer combat loop with automatic shared rewards.

## New

- Winning an ordinary party battle automatically creates a victory reward bundle.
- Every party member receives the same completion XP bonus.
- Gold is deposited into the shared party treasury.
- One level-appropriate trophy is added to the shared inventory.
- Existing per-kill XP remains available to the hero who defeats an enemy.
- `/rewards` shows the ten latest victories and their rewards.
- Reward grants are recorded in `battle_reward_history`.

## Reliability

- Party XP, shared gold, inventory loot, reward history, and combat deletion are committed in one SQLite transaction.
- Every combat receives a stable battle ID.
- Repeated or concurrent final clicks cannot grant the same reward twice.
- Existing active party battles created by v4.5 or v4.6 receive an ID automatically when completed.

## Reward calculation

- Completion XP is based on the total XP value of all enemies and divided across the party.
- Gold scales with party level, enemy count, and battle length.
- Trophy quality scales with party level and uses items already supported by inventory, support, forge, and tactical systems.

## Compatibility

- Solo combat rules are unchanged.
- Existing databases require no manual migration.
- No environment or Telegram token changes are required.

## Upgrade

Pull the latest `main`, install dependencies, restart the bot, and send `/start`:

```bash
git pull
pip install -r requirements.txt
python -m app.main
```

After a party victory, use `/rewards` to inspect the XP bonus, gold, and trophy.
