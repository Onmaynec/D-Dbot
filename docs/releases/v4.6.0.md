# D&D Telegram Master v4.6.0 — Party Support

Version 4.6.0 adds battlefield healing to the multiplayer combat system introduced in v4.5.

## New

- `/support` opens the party support interface during an active multiplayer battle.
- Any living player may spend their turn to heal a wounded ally.
- Normal and greater healing potions are taken from the shared party inventory.
- A potion can return an unconscious hero from zero HP to the battle.
- The support screen shows party HP, completed turns, waiting players, and available potions.
- If support is the final action of the round, the shared enemy phase starts immediately.
- Support actions are recorded in `party_support_history`.

## Reliability

- Inventory consumption, restored HP, party member data, acted-player list, enemy phase, and round number are committed in one SQLite transaction.
- Repeated or concurrent clicks cannot consume multiple potions or grant an extra turn.
- Missing items and full-health targets roll back without changing combat state.

## Compatibility

- Existing v4.5 party combats work without manual migration.
- Solo healing from the normal inventory remains unchanged.
- No environment or Telegram token changes are required.

## Upgrade

Pull the latest `main`, install dependencies, restart the bot, and send `/start`:

```bash
git pull
pip install -r requirements.txt
python -m app.main
```

During a party battle, use `/support`, choose a wounded hero, and select a healing potion.
