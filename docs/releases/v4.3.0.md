# D&D Telegram Master v4.3.0 — Forge & Salvage

Version 4.3.0 closes the party economy loop by adding a permanent forge.

## New

- `/forge` opens the Black Hammer forge.
- Craft greater healing potions, shield scrolls, and phoenix feathers.
- Salvage one unwanted item at a time for gold based on rarity.
- All rewards and costs use the existing shared party inventory and treasury.
- Crafting and salvage operations are atomic SQLite transactions.
- Every operation is recorded in `forge_history`.

## Safety and compatibility

- Existing databases are upgraded automatically with `CREATE TABLE IF NOT EXISTS`.
- Failed recipes do not consume partial ingredients or gold.
- Stale or repeated salvage buttons cannot remove the wrong item.
- No Telegram token or configuration changes are required.

## Upgrade

Pull the latest `main`, install dependencies, restart the bot, and send `/start`:

```bash
git pull
pip install -r requirements.txt
python -m app.main
```

Open the new system with `/forge`.
