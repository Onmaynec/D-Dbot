# D&D Telegram Master v5.0.0 — Adventure Reforged

Version 5.0 is a major gameplay and presentation overhaul. It connects character progression, equipment, party combat, story choices, shared rewards, and the party economy into one understandable loop.

## Interactive combat

- `/actions` opens a dedicated tactical turn panel.
- Risky attack applies `-2` to hit and `+4` damage on top of weapon damage.
- Defensive stance spends the turn to increase armor class and reduce incoming damage.
- Equipped armor and trinkets affect enemy hit calculations.
- Equipped weapons increase physical damage.
- Staves and magical trinkets increase spell damage without changing the displayed spell attack roll.
- Existing `/support`, `/tactics`, normal attacks, spells, party rounds, and victory rewards remain available.

## Equipment

- `/equipment` opens the character equipment hub.
- Every party member owns their equipment separately.
- Three slots are available: weapon, armor, and trinket.
- Twelve items cover common, rare, and epic progression tiers.
- Purchases use the shared treasury.
- Equipment changes are blocked while combat is active.
- Ownership and actions are stored in `owned_equipment` and `equipment_history`.

## Story choices

- `/choice` creates an encounter with three distinct decisions.
- Each option uses Strength, Dexterity, Intelligence, Wisdom, or Charisma.
- The check uses the average ability score of the current party.
- Consequences can grant gold, award loot, consume gold, or damage every living hero.
- An unresolved event persists until the party makes a decision.

## Casino

- `/casino` opens the in-game tavern casino.
- Coin flip, dice duel, and rune slots use only fictional party gold.
- Rune payouts include pairs, triples, and a royal jackpot.
- Balance validation, stake, payout, and history are one SQLite transaction.
- A daily stake limit protects the shared treasury.

## Interface

- The reply keyboard is regrouped around character, story, combat, world, and economy.
- Character cards show HP bars, equipment, and final gear bonuses.
- Enemy cards show readable HP bars and armor class.
- `/start` is now a four-step onboarding guide.
- `/help` explains the real game loop instead of listing disconnected features.

## HQ scenes

- The media system prefers sixteen source PNG scenes in `assets/images_hq`.
- Document mode sends the original PNG without Telegram photo recompression.
- Formatted text is sent as a separate message, preserving readable HTML formatting.
- Existing JPG files remain an automatic fallback.
- `SHA256SUMS` and `scripts/verify_hq_assets.py` verify the original upload bytes.
- When the original PNG files are present in `assets/images_hq`, the release workflow attaches them individually rather than creating an archive. The supplied files can also be installed separately and verified by checksum.

## Reliability and compatibility

- Existing campaigns, party members, inventory, wallet, combat history, rewards, and active fights remain compatible.
- New tables are created lazily with `CREATE TABLE IF NOT EXISTS`.
- Equipment, casino, story choices, and combat choices use atomic SQLite transactions.
- Repeated combat callbacks cannot produce an extra action or duplicate a victory reward.
- No environment or Telegram token changes are required.

## Upgrade

```bash
git pull
pip install -r requirements.txt
python -m app.main
```

Send `/start` after restarting. Download the supplied PNG files individually and run:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install_hq_assets.ps1
python scripts\verify_hq_assets.py
```
