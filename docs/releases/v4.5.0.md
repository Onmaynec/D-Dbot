# D&D Telegram Master v4.5.0 — Party Combat

Version 4.5.0 turns the existing party roster into a real multiplayer combat system.

## New

- Every living party member acts once per round with their own hero.
- Physical attacks use that member's Strength, level, and proficiency.
- Spells use that member's Wisdom and level.
- The enemy phase begins only after every living member has acted.
- Enemies choose targets from the living party and persist damage to each member.
- The combat screen shows who has acted, who is waiting, and who is unconscious.
- Repeated and concurrent button presses cannot grant an extra turn.
- Party HP, XP, acted-player list, enemy state, and round number are saved atomically.
- Attacks and spells are recorded in `party_combat_history`.

## Tactical item integration

- Shield Scroll grants its armor bonus to the whole party for the enemy phase.
- Phoenix Feather revives the first party hero reduced to zero HP.
- `/tactics` remains available during multiplayer battles.

## Compatibility

- Chats without joined party members continue to use the existing solo combat flow.
- Existing databases and active solo combats remain compatible.
- No environment or Telegram token changes are required.

## Upgrade

Pull the latest `main`, install dependencies, restart the bot, and send `/start`:

```bash
git pull
pip install -r requirements.txt
python -m app.main
```

Have each player join through **Party**, then start a battle. Every participant may attack or cast one spell per round.
